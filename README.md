# Dynamic Functional Connectivity Toolbox (`dFC_toolbox_app`)

This repository includes portions of the following freely available software:
  - Brain Connectivity Toolbox available at https://www.nitrc.org/projects/bct/
  - Tools for NIfTI and ANALYZE image available at https://www.mathworks.com/matlabcentral/fileexchange/8797-tools-for-nifti-and-analyze-image

The `dFC_toolbox_app` is a MATLAB-based graphical application for analyzing and visualizing **dynamic functional connectivity (dFC)** using time-resolved fMRI data. It enables researchers to quantify temporal variability, identify network states via clustering, and visualize state-specific connectivity on a brain template.

## Overview

This toolbox is intended for use **after preprocessing with the [CONN toolbox](https://www.nitrc.org/projects/conn)**, a MATLAB-based pipeline for fMRI analysis. It expects input `.mat` files generated by CONN and offers:

- Temporal metrics: **temporal variability (TV)**, **transition frequency (TF)**, **inter-window similarity**
- Clustering of dFC states using **k-means**
- Interactive GUI for **visualization**, **network filtering**, and **exporting results**
- Brain overlays using the **Schaefer** or **AAL3** atlases

## Requirements

- MATLAB R2020a or later
- Toolboxes:
  - Statistics and Machine Learning Toolbox
  - Image Processing Toolbox
- Preprocessed data from the **CONN toolbox** with windowed ROI-to-ROI time series extracted

## Installation

1. Clone the repository:

   ```
   git clone https://github.com/your-username/dFC_toolbox_app.git
   cd dFC_toolbox_app
   ```

2. In MATLAB, add the toolbox to your path:

   ```matlab
   addpath(genpath('path/to/dFC_toolbox_app'))
   ```

3. Launch the GUI by running:

   ```matlab
   dFC_toolbox_app
   ```

## Input Requirements

This app requires `.mat` files derived from **CONN toolbox output**, typically containing:

- ROI time series for each subject and condition
- Parcellated atlas information (e.g., Schaefer 200, AAL3)
- Optional lesion masks (for stroke-related analyses)

### Expected File Content

The following variables are expected or constructed using included scripts:
- `BOLD` or ROI time series (from CONN)
- ROI metadata (e.g., `ROI_MNI_V7_List.mat`)
- Network assignments (from `get_schaefer_networks.m`, etc.)
- `dFC` matrices computed using `compute_dFC.m`

## Example Workflow

1. **Preprocess fMRI data in CONN**, including denoising and extracting ROI-level time series using a supported atlas (e.g., Schaefer-200 or AAL3).

2. **Locate the output `.mat` files** generated by CONN:
   - These are typically saved in your CONN project directory under `results/preprocessing` and `results/firstlevel`
   - Example filenames:
     - `ROI_Subject001_Condition001.mat`
     - `resultsROI_Subject001_Condition001.mat`
   - Each file contains the denoised ROI time series for one subject and condition.

3. **(Optional)**: Copy the desired CONN output `.mat` files into a separate folder for use with the dFC toolbox.

4. **Start a new project** from the GUI:
   - Click **Start New Project**
   - When prompted, select the **folder** containing the relevant `.mat` files (do not select individual files)
   - Choose your atlas and configure parameters such as window length, step size, and number of clusters

5. **Run Temporal Metrics Analysis**:
   - Click **Compute Temporal Metrics**
   - View the inter-window similarity heatmap and computed metrics
   - Export temporal variability (TV), transition frequency (TF), and inter-window similarity (IWS) as `.csv` files

6. **Run State Analysis**:
   - Click **Run States Analysis**
   - View elbow plot and PCA-based clustering
   - Visualize each state's mean dFC on a brain template using ROI/network filters

7. **Export Figures and Results** as publication-ready images or summary data

## Atlas Support

The app includes functionality for two common ROI parcellations:

### Schaefer Atlas
- 200-region parcellation
- Network assignments via:
  - `get_schaefer_networks.m`
  - `get_schaefer_networks_200.m`

### AAL3 Atlas
- High-resolution anatomical atlas
- Functions include:
  - `convert_2_AAL3_indices.m`
  - `get_AAL3_vox_coor.m`

Both atlases rely on voxel-to-surface coordinate mapping (`mni2xy_v2.m`) and ROI metadata (`ROI_MNI_V7_List.mat`).

## Output

- Figures:
  - Inter-window similarity matrices (with/without transition outlines)
  - Elbow plot and PCA scatterplot
  - Brain overlays of state-specific dFC
- CSV files:
  - `mean_var.csv` – temporal variability
  - `TF_comm_struct.csv` – transition frequency
  - `mean_similarity.csv` – inter-window similarity
- Optional:
  - `state_occ.csv` – state occupancy
  - Project `.mat` files for saving and resuming sessions
